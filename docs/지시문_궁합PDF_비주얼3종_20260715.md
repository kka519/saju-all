## 2. 합충 관계도 (p9~10 리스크 공시 도입부)

이 리포트의 대표 이미지. 신규 `couple-relations-chart.ts`:

- 레이아웃: 본인 4기둥(상단 행, 골드) vs 상대 4기둥(하단 행, 블루), 8글자 한자 노드
- 연결선: **합 = 골드 실선**, **충 = 붉은 점선**, 파·형·해 = 회색 점선. 각 선에 라벨(예: 甲己合, 辰戌沖)
- 데이터: 코드가 두 명식 교차 계산. 천간×천간(합·충), 지지×지지(육합·삼합 일부·충·형·파·해). 관계 없는 조합은 선 없음
- 선이 많아 겹치면: 합충(강한 관계)만 기본 표시, 파·형·해는 얇게. 최대 가독 우선
- 범례 필수 (골드 실선=끌림/결합, 붉은 점선=마찰 지점)
- 관계도 아래 LLM 본문이 이 그림을 해설하는 구조 — 프롬프트에 코드가 계산한 관계 목록을 "[이 관계만 언급]" 블록으로 주입 (진실 원천 단일화, 어제 진미파 오류 재발 방지)

## 3. 2인 세운 교차 곡선 (p16 백테스트 / p17 3년 캘린더)

- `seun-chart.ts` 확장 또는 `couple-seun-chart.ts` 신설: 두 시리즈 오버레이 (골드=본인, 블루=상대)
- 데이터: 양쪽 full_analysis의 세운 점수(luckyloveme). **곡선 수치는 100% 코드 주입** — LLM 생성 금지
- X축: 과거 3년 + 향후 4년 (연도+간지 라벨, 코드 계산)
- **동반 상승 연도 하이라이트**: 코드가 "두 사람 점수가 처음으로 함께 양수(또는 함께 상승)가 되는 해"를 탐색해 골드 음영 밴드 + 마커 표시. 해당 연도는 프롬프트에도 주입돼 본문·공유 카드와 일치해야 함
