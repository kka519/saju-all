couple-match(19,900원)를 채팅형 700~900자에서 **A4 20페이지 PDF 리포트**로 전면 개편.
브랜드는 LUNA LIFE RESEARCH 라인(두리 아님). 클로드 코드는 이 문서를 사양서로 사용.

## 0. 착수 조건·전제

## 1. 확정 결정 (7/15 사장님)

- **분량**: A4 20페이지 PDF. 근거: 19,900원에 2,000자 텍스트는 "성의 없음+비쌈" 체감. 고객이 돈 쓰고 아깝다는 생각이 들면 안 됨
- **브랜드**: LUNA LIFE RESEARCH "합병 리서치" 컨셉 — 두 종목(두 사람)의 합병 실사 보고서. 리포트 엔진·NAVY/GOLD 토큰·백테스트 장치 재활용
- **진열 이동**: couple-match를 홈 ③두리의 연애 풀이 → ②LUNA LIFE RESEARCH 섹션으로. **구매 동선(카드·상세·대기·완료·PDF)에 두리 등장 금지** 원칙이 couple-match에도 적용됨 (7/14 별도 페르소나 원칙 확장)
- **속궁합 포함, 수위 상한 있음**: 전용 1페이지(케미스트리 리포트). 도화·홍염·일지 기반으로 끌림·스킨십 케미·속도 차이를 솔직하고 구체적으로 다루되, **노골적 성행위 묘사는 프롬프트 금지 + 게이트 차단**. 근거: PG 심사(성인 콘텐츠 분류 리스크)·메타 광고 정책. PG 심사 통과 후 수위 재검토 가능
- **love-consulting(29,900)**: 비노출 아님 — 궁합 리포트보다 상위 가치로 재설계(별도 회의, §8)

고객이 궁합에서 진짜 원하는 것 (우선순위 — 7/15 회의):

## 4. 케미스트리 리포트(p13~14) — 속궁합 강화판 사양 (7/15 밤 확정)

"심심하면 안 하느니만 못하다"(사장님) — 속궁합은 구매 이유 최상위 축. 잠자리·밤·욕구·주도권을 정면으로 다루되, 행위 묘사 없이 **온도·속도·리듬·주도권의 언어**로 쓴다. 2페이지 8블록.

### 8블록 구조

1. **심리 저격 훅** — 현재형 적중으로 시작. 예: "다툰 날 밤, 오히려 서로를 찾은 적 있지 않습니까. 두 분은 낮의 언어보다 밤의 언어가 잘 통하는 구조입니다." (합·충 교차 기반, 커플마다 다르게)
2. **밤의 페르소나 카드 A/B** — 각자 "낮과 밤의 갭" 진단. 유형 사전(코드가 십신 분포로 판정, LLM은 준수): 평소 얌전·밤엔 확신형(살인상생) / 꽂혀야 켜지는 스위치형(인성 과다) / 해주고 반응에 불붙는 형(식상) / 리드받고 싶은 형(관성) / 분위기·연출에 반응하는 형(편재) / 밀당 즐기는 형(비겁)
3. **욕구 온도계** — 두 사람의 욕구 크기·빈도 성향을 게이지 2개로 나란히. 온도차가 크면 정면으로 말한다: "이 커플의 다툼 원인은 낮이 아니라 밤에 있는 경우가 많습니다."
4. **주도권 구조** — 누가 이끌고 누가 따르는가(관성·비겁·식상 교차). 둘 다 리드형이면: "침대에서도 힘겨루기가 벌어지는 조합 — 승부를 겨루지 말고 번갈아 이기십시오."
5. **예열-지속 곡선** — 빨리 타오르고 빨리 식는 형(목화·식상) vs 늦게 데워져 오래 가는 형(금수). 두 곡선을 겹친 미니 그래픽 — 겹치는 구간이 좁으면 그게 온도차의 정체
6. **스킨십 언어** — 반응하는 결의 차이: 넓고 은은하게(정인) vs 한 점 깊게(편인), 살결 민감형(관성·수 기운). "터치의 언어가 서로 다른 커플" 프레임
7. **밤의 시그널 사전** — 서로 오해하는 신호 2~3개 번역 + 처방. 예: "그대의 침묵은 거절이 아니라 예열입니다 — 광훈님, 속도를 늦추면 답이 옵니다."
8. **온도 타이밍 예고(라이트)** — 향후 수개월 중 두 사람의 온도가 함께 오르는 구간 1개 언급(운에서 식상·관성·충 — 코드 탐색). 상세 캘린더는 Phase 2

### 수위 기준선

- **허용**: 잠자리, 밤, 욕구, 스킨십, 주도권, 달아오르다, 예열, 온도, 밀당, 몸의 대화, 리드 — 정면으로, 헤지 없이
- **금지(게이트 유지)**: 성행위 직접 묘사, 신체 부위 명칭, 외설 표현. term-guard 패턴 금지어 목록
- 근거: PG 심사·메타 광고 정책. **PG 승인 후 Phase 2에서 수위·밀도 재상향 (사장님 결정 사항)**

### Phase 2 (PG 승인 후 증축 — 페이지 교체 없이 확장)

- 욕구 균형 정밀 진단(구조 유사 + 한쪽 열세 조합 경고 포함)
- **온도 캘린더**: 월 단위로 두 사람의 욕구 상승 시기 표시(운에서 식상·관성·충 유입) — 코드 계산, 경쟁 서비스가 못 하는 차별화
- 민감 유형 심화(넓고 은은한 형 vs 좁고 깊은 형), 표현 수위 상향

## 5. 진실 원천 단일화 (게이트 사양)

today-fortune 패턴("코드가 판정, LLM은 준수, 게이트가 검증") 전면 적용:

1. **관계 지수·등급**: 코드가 계산 — 천간합·지지합충 카운트, 오행 보완도, 용신 교차 매트릭스(내 용신이 상대에게 희신인가 기신인가). 산식은 구현 시 설계하되 **LLM 임의 점수 부여 금지**, 게이트가 본문 등급 표기와 코드 판정 일치 검증
2. **용신 게이트**: 본인·상대 용신/희신/기신 오행을 full_analysis에서 코드가 추출(buildMyeongsikView 재사용), "[이 값만 사용]" 블록 주입. 출력 파싱해 불일치 시 재생성(파트당 상한 2회, 리포트 재시도 패턴 재사용). **mock 폴백 시 용신 언급 금지 분기** — 데이터 없으면 지어내기 원천 차단
3. **상대 일간 인용 게이트**: 양쪽 일간이 본문에 실제 등장하는지 검증 (가짜 궁합 2차 방어)
4. **연도 라벨**: 코드 계산·주입, LLM 임의 부여 금지
5. **용어 규칙**: term-guard 커플판 — 신살 원어 본문 금지(표·각주만), 12운성 원어(死 등) 노출 금지, 흉살은 일상어 번역. 투자 용어 주객전도 원칙 동일

## 9. 7/15 밤 회의 — 유튜브 벤치마크 분석 반영 (궁합 본편 보강)

시중 궁합 콘텐츠 스크립트 8건 분석 결과, 본편에 다음을 추가한다.

### 추가 로직 (전부 코드 계산, LLM은 해설만)

1. **도입 훅 — "결혼은 유일한 개운법"**: 서머리에 고정 문구 방향 — "명식은 상장 시점에 정해진 포트폴리오. 합병 상대는 당신이 직접 고르는 유일한 대형 딜." 리포트 존재 이유를 세우는 프레임
2. **병(病)-치유 매트릭스** (p7~8 시너지의 중심 분석): 각자 명식의 병 글자(기신·구신·문제 구조)를 상대가 가진 글자가 해소하는가(합으로 제거·설기). "이 사람은 당신에게 약입니까"가 섹션 질문. 쌍방향 2행 매트릭스로 시각화
3. **끌림의 숨은 장치** (p6 보강): 천을귀인 교차(상대가 내 귀인 글자 보유 = 설명 안 되는 끌림·이별 어려움) + 공망 교차(같은 공망 = 묘한 동질감). gongmang.ts 재사용
4. **관계 유형 태그** (p2 서머리): 일간 십신 관계로 3분류 — 관-재형(정배열) / 식상-인성형(모자형·실커플 다수) / 비겁형(남매형). 코드 판정, 등급 옆 표기
5. **배우자궁 자체 진단** (p15): 교차 분석 전에 각자 명식의 일지 안정성(자체 충·형 여부)을 먼저 진단 — "터가 흔들리는지"를 보고 나서 상대와의 교차를 본다

### 지수 산식 원칙 추가

- **조건부 가중치**: 합=가점, 충=감점의 기계적 산식 금지. 합 과다 명식에는 충이 순기능(정체 해소) — 명식 맥락에 따라 부호가 바뀌는 조건 로직으로 설계
