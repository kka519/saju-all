Cowork 검토 결과. v4는 **조건부 통과** — 아래 수정 후 재생성 검증으로 Phase B 콘텐츠 마감.
기준 문서: `기획_궁합리포트_합병리서치_20260715.md`(마스터), `검수요청_궁합_fewshot샘플_20260715.md`(매핑표).

## 1. 회복 시계 판정 로직 교체 (type-names.ts) — 사장님 확정: 정확성 기준

현행 `judgeRecoveryClock`은 OR 로직(양간이면 무조건 반나절)이라 매핑표 원문("비겁·양간 **우세**" / "인성·음간 **우세**")과 다름. 인구 절반이 자동 반나절이 되고, 김경아(비겁 0·인성 2·갑 양간)가 반나절로 오판정됨.

교체 사양:

```
비겁 > 인성 → 반나절 시계
인성 > 비겁 → 하루반 시계
동률       → 양간이면 반나절, 음간이면 하루반
```

- 검증 케이스: 김경아 → **하루반 시계**(인성 2 > 비겁 0), 최광훈 → **반나절 시계**(비겁 5 우세). 두 시계가 달라져 승인 샘플 1의 킬러 장면(시계 다름 → 36시간 처방)이 복원됨
- 회복 시계 언급 필드(서머리·시너지·리스크 3필드·로드맵)의 기존 v4 서사("같은 회복 속도 = 최대 자산")는 재생성 시 자동 교체되는지 확인할 것 — 프롬프트에 하드코딩 잔재 금지

## 2. 온도 타이밍 예고(케미 ⑧) — 월운 기반 재지시 (7/15 지시 미반영 확인)

v4 여전히 2028년 세운 기반. 마스터 §4-⑧ 원문 = "**향후 수개월** 중 온도가 함께 오르는 구간 1개(운에서 식상·관성·충 — 코드 탐색)".

## 3. 회복 시계 유형명 정확 표기 (v4 잔여 결함)

riskDisclosure·riskManagementSelf·riskManagementPartner에 유형명 누락 재발 방지:

- 프롬프트에 "riskDisclosure에 두 사람의 회복 시계 유형명('반나절 시계'/'하루반 시계')을 정확 표기로 최소 1회" 강제
- §1 수정으로 두 시계가 달라지면 샘플 1 패턴을 따라 자연 표기될 가능성 높음 — 게이트는 현행 유지

## 4. §9 본편 보강 5종 구현 — 사장님 확정: 이번 지시에 포함

마스터 §9 사양대로. 전부 **코드 계산·주입, LLM은 해설만**:

1. 도입 훅(p2 서머리) — "명식은 상장 시점에 정해진 포트폴리오, 합병 상대는 직접 고르는 유일한 대형 딜" 방향의 고정 프레임
2. 병-치유 매트릭스(p7~8 시너지의 중심 분석) — 각자 병 글자를 상대가 해소하는가, 쌍방향 2행. 섹션 질문 = "이 사람은 당신에게 약입니까"
3. 끌림의 숨은 장치(p6) — 천을귀인 교차 + 공망 교차(gongmang.ts 재사용). 신살 원어 본문 금지 규칙 준수(번역어로)
4. 관계 유형 태그(p2) — 관-재형/식상-인성형/비겁형 코드 판정, 등급 옆 표기
5. 배우자궁 자체 진단(p15) — 교차 전에 각자 일지 자체 충·형 여부 먼저
- 지수 산식 조건부 가중치 원칙(§9 하단) 함께 적용 — 합=가점·충=감점 기계식 금지

## 5. 처방 행동 성별 중성화 — 사장님 확정: 교체

v4에서 김경아(여성) 처방이 "커피를 타주거나 밥상을 차리는 행동". 명제형 위반은 아니나 리뷰 리스크.

- 프롬프트 지시 추가: 가사 행동(밥상·요리·커피 등)을 화해 처방으로 특정 인물에 배정 금지. 중성 예시 뱅크 제공 — 먼저 인사 건네기, 산책 제안, 상대가 좋아하는 것 챙겨주기, 평소 루틴 먼저 복구하기 등

## 6. 문장 결함 — 코드측 원인 1건 + 재생성 확인 2건

1. **"진토예술적 감수성"(p15)** — 주입 데이터 이어붙음 의심(글자+해설 사이 구분자 누락). 명식 뷰 → 프롬프트 직렬화 구간 확인·수정
2. "과열 리스크를 키우는 부담을 키우는 기운"(p9~10, 중복) / p2 "합병은 가능하나 ~ 최대 자산이다"(역접 뒤 긍정) — LLM 생성 결함이므로 재생성본에서 재발 여부만 확인, 반복 시 보고

## 7. 게이트 오탐 수정 (검증 노이즈 제거)

1. 세운 수치 게이트: 근접 윈도우 → **연도 토큰 귀속 매칭**(수치를 직전 등장 연도에 귀속). v4 오탐 3건 유형("2029년 …+59…2027년의 긴장"에서 +59를 2027 것으로 오판) 재발 방지
2. 호칭 게이트: "본인/상대" 정상 대명사 용법("최광훈님 본인은", "본인 월주와 상대 월주") 허용 처리

## 8. 검증 절차 (완료 조건)

1. 김경아×최광훈 재생성 1회 → 검토 페이지 v5 갱신
2. **다른 상대 고정 케이스 1건 신설·생성** — 현 테스트 커플이 few-shot 샘플 커플과 동일 인물이라 30자 복사 게이트가 검증력 없음. 샘플과 겹치지 않는 생년월일로 고정 케이스를 새로 정해 이 문서에 기록하고, 복사·유형명·세운 게이트 실검증
3. 두 건 모두 게이트 통과 + 잔여 이슈 0건 상태로 Cowork 검토 요청
