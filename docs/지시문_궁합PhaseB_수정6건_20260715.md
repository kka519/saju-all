## 1. 용어 규칙 위반 다수

화개살·반안살·문창귀인·천주귀인·재고귀인·제왕·건록이 본문에 원어 노출됨. 기획서 §5.5 적용: 신살·12운성 원어는 본문 금지(표·각주만), 일상어 번역 사용. 프롬프트 단계에서 줄이고 게이트로 잡을 것.

## 2. 산술 표현 모순

"원국 여섯 자리 중 여섯 개가 토" ↔ 같은 문단 "75퍼센트" 충돌 (8자 중 6개 = 75%가 맞는 표현으로 추정). **글자 개수·비율 등 산술 표현은 LLM 생성 금지** — 코드가 계산해 주입하고 LLM은 인용만.

## 3. 백테스트·캘린더 점수 출처 확인 (출고 가부 항목)

draft의 세운 점수(+15, -79, -107, +66 등)가 luckyloveme 데이터를 코드가 주입한 값인지, LLM 생성인지 확인·보고할 것. LLM 생성이면 즉시 수술: 양쪽 full_analysis의 세운 점수를 코드 추출·주입 + 출력 일치 게이트. (기획서 §5.2~5.4와 동일 원칙)

## 4. 백테스트 헤지 과다

"엇갈렸을 가능성이 높다", "체감되었을 수도" 남발로 적중 체감이 죽음. 백테스트 섹션은 단정에 가깝게: "2025년, 유독 힘들지 않으셨습니까" 톤. 헤지는 섹션당 1회 이하로 프롬프트 지시.

## 5. 호칭

"본인/상대" → 입력받은 이름 기반 "경아님/광훈님" 호칭으로. 이름 미입력 시에만 "본인/상대방" 폴백.

## 6. 분량·지면

현재 섹션당 300~500자 × 16 ≈ 6,500자 — 20페이지에 부족. 대응: ①파트별 min_chars 상향(인생 리포트 기준 준용) ②비주얼로 지면 보완 — `지시문_궁합PDF_비주얼3종_20260715.md`(명식표 2단·합충 관계도·2인 세운 교차 곡선) 병행 ③케미스트리 2페이지 확장(기획서 §4)
